# Прогноз оттока клиентов

End-to-end модель для выявления клиентов телеком-компании с высоким риском ухода. Проект показывает не только качество ранжирования, но и выбор практического порога для программы удержания.

## Результаты

| Метрика | Отложенная выборка |
|---|---:|
| Accuracy | 0.7622 |
| Precision | 0.5399 |
| Recall | 0.7059 |
| F1 | 0.6118 |
| ROC-AUC | 0.8413 |
| PR-AUC | 0.6326 |

Выбрана сбалансированная Logistic Regression с порогом 0.60. На отложенной выборке модель нашла 264 из 374 ушедших клиентов, пропустила 110 и отправила на дополнительную проверку 225 клиентов, которые не ушли.

## Что сделано

- Числовая и категориальная предобработка объединена с моделью в воспроизводимый scikit-learn pipeline.
- Несколько моделей сравнены на отдельной валидационной выборке.
- Проанализированы ROC- и precision-recall-кривые.
- Порог выбран с учётом разной стоимости пропущенного оттока и лишнего предложения.
- Финальная оценка выполнена один раз на отложенных данных.

## Бизнес-интерпретация

ROC-AUC показывает качество ранжирования, но не определяет, кому именно предлагать удержание. Рабочий порог необходимо рассчитывать из стоимости бонуса, ожидаемой маржи клиента и вероятности успешного удержания.

## Ограничения и развитие

Для промышленной версии потребуются временная валидация, калибровка вероятностей, uplift-модель для оценки эффекта предложения, мониторинг дрейфа и пересмотр порога при изменении экономики программы.
